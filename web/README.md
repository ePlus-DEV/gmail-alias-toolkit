# Gmail Alias Toolkit Web

Static landing page for Gmail Alias Toolkit, built with Vite, React, Tailwind CSS and BeUI-style motion interactions powered by Framer Motion.

## Local development

```bash
yarn install
yarn workspace gmail-alias-toolkit-web dev
```

## Build

```bash
yarn workspace gmail-alias-toolkit-web build
```

The production build is generated in `web/dist` and deployed to GitHub Pages by `.github/workflows/deploy-pages.yml`.
